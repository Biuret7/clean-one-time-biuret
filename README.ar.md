# CleAN-oNE TIME — Biuret V4

سكربت Batch لنظام Windows يجمع أوامر إغلاق بعض العمليات، وتنظيف الملفات المؤقتة، وإعادة تشغيل مستكشف الملفات، وصيانة الشبكة.

[English](README.md) · [المشاكل المعروفة](KNOWN_ISSUES.md) · [المساهمة](CONTRIBUTING.md)

> **نسخة قديمة تحتاج مراجعة قبل التشغيل.** يحتوي V4 على أوامر حذف ملفات ومسح سجلات Windows، وقد يقطع الاتصال بالشبكة أو يحاول إعادة ضبط الجدار الناري. فيه مشاكل معروفة بتسلسل التنفيذ، ولم يتم تشغيله أو اختبار توافقه أثناء تجهيز هذا المستودع. لا تستخدمه على جهازك الأساسي أو جهاز إنتاج.

## محتويات النسخة

الملف `CleAN-oNE TIME [Biuret] V4.bat` هو السكربت المرفق نفسه، مع تغيير اسم الملف وعنوان نافذة الأوامر إلى Biuret. بقية الأوامر بقيت كما هي.

يحتوي المصدر على أوامر لإغلاق عمليات مرتبطة بالمحاكيات وبعض عمليات Windows، وإيقاف خدمتين، وإعادة تشغيل Explorer، وتجديد عنوان الشبكة، وحذف ملفات مؤقتة، ومسح سجلات الأحداث. يوجد قسم لاحق لإعادة ضبط مكونات الشبكة والجدار الناري؛ الوصول إليه يتأثر بمشاكل فحص صلاحيات المسؤول وتسلسل القفز بين الأقسام.

وجود الأمر في الملف لا يعني أنه يعمل أو أنه سيُنفّذ في كل تشغيل. التفاصيل موجودة في [المشاكل المعروفة](KNOWN_ISSUES.md).

## التنزيل والمراجعة

نزّل المشروع من **Code → Download ZIP** أو استخدم:

```text
git clone https://github.com/Biuret7/clean-one-time-biuret.git
```

افتح ملف `.bat` بمحرّر نصوص لمراجعته؛ النقر عليه مرتين يشغّله. إذا أردت تقييم سلوكه، استخدم آلة افتراضية مؤقتة مع لقطة استعادة وبدون بيانات شخصية أو اعتماد على اتصالها بالشبكة.

السكربت يستهدف `cmd.exe` ويستخدم أدوات Windows. بعض الأوامر تتطلب صلاحيات مسؤول، وأوامر قديمة فيه غير متاحة في Windows الحديث. لا يوجد إصدار Windows معتمد بالتجربة حاليًا.

لا تتوفر في V4 معاينة بدون تنفيذ، أو قائمة لاختيار عمليات التنظيف، أو نسخ احتياطي، أو تراجع عن التغييرات. لا توجد ادعاءات مثبتة بتحسين الأداء أو نجاح كل عمليات التنظيف.
